# DSH 大肥鱼按需部署 Skill

面向已安装 DeepSeek Harness 的用户，按需检查和部署大肥鱼桌宠、Aurabot QQ、聊天语音、RVC 翻唱、歌曲来源、成品库和社交模块。支持只检查、只补缺项，不默认安装整套。

## 使用

将本仓库交给有文件操作能力的 DSH Agent，要求它安装此 Skill，阅读 `SKILL.md` 并按需求执行。普通下载、解压和配置由 Agent 完成；扫码、账户验证与需要本人处理的许可步骤由用户完成。详细规则和版本兼容性见 `SKILL.md` 与 `references/`。

QQ 网关默认改为 **NapCatQQ + OneBot v11**：已有可用环境先复用；缺失且用户选择 QQ 部署时，由 Agent 从官方获取并校验、安装、准备连接，扫码及身份验证由用户本人完成。只修改技能不自动切换正在运行的网关。见[自动部署流程](references/napcat-deployment.md)。

本项目不包含 DSH、Aurabot、QQ 网关、基础声音模型权重、歌曲、个人配置或登录凭据。另附十一款小型合成音色预设及独立非商用许可；基础组件仍需独立获取并遵守其许可。网易云、QQ 与各组件的接口可能变化；CPU 路线和其他机器的功能必须各自验证。

已补入按需的 Breeze TTS 2 第三方 C++/Vulkan 本机语音、原有四款原创合成音色准备、RVC 追加音色校验导入、独立可见的讲话/翻唱音色与回复方式设置（仅文字/仅语音/文字＋语音/自动），以及既有QQ网关断线的定向检查修复。脚本使用实际路径、默认只检查；不包含基础模型或个人资料，不因选择其中一项而安装全部。详见 `references/breeze-tts2-cpp.md`、`rvc-extra-voices.md`、`voice-controls.md` 与网关故障参考。

另含可安装的 **Breeze CPP / RVC 统一翻唱插件**：“音色切换”统一设置引擎/音色/清唱与成品复用，“翻唱制作”只负责选歌、片段、试听及实际任务记录。本地已导入原曲优先，没有匹配再搜网易云；网搜普通录音室版优先，明确点现场版则遵从。成品优先开启只复用匹配当前声音的作品，关闭重新换声但保留分离缓存。QQ点歌严格按选定引擎处理，完成后只提交指定版本一次；本机试听不自动发QQ。当前支持1–180秒片段，Breeze不保证旋律保真。复用既有环境，不含用户歌曲、索引、私人参考克隆或额外讲话轮换功能。见[翻唱部署](references/breeze-cover.md)、[路由与复用](references/cover-routing-and-reuse.md)。

支持用户指定目录的**自动入库**：每5秒扫描第一层新音频，按内容去重，不自动制作或外发。本地以登记歌名为主，允许使用其它人的翻唱，不因普通原歌手提示跳过本地；明确指定版本时仍尊重要求。目录路径和索引只在使用者本机生成，分享包不预置个人目录。

网易云自动选源默认“原唱优先、不强制原唱”：没有可用原唱时可选同名普通演唱来源，排除钢琴/伴奏/纯音乐/Type Beat，先检查完整音频可用性；明确点原唱版或指定版本时不放宽，也不把替代录音冒称原唱。

新增可直接导入的固定讲话音色：**撒娇女友、御姐女王、懒羊羊风格（近似）、台湾腔甜妹（文字V2）、傲娇大小姐、迷糊女大学生、霸道女总裁、男高中生、男大学生**。十一款 `.breeze` 共约74KB，附SHA256、风格指令和只读/无覆盖导入脚本；保留当前讲话、翻唱和回复方式。台湾女生这款说普通话并保留自然台湾腔，懒羊羊这款只是合成近似、非动画原声。见[固定音色包](references/breeze-saved-presets.md)。

首次安装、重装或补齐功能均面向普通用户，不另设教学专用版。NapCat 通过通用 OneBot 接口接入，不补丁修改宿主的旧网关管理器。配置助手默认只检查；连接验证覆盖机器人身份、在线、事件和媒体。网关专用旧安装/查找/注入脚本已移出技能。基础准备完成仍有待办时继续其他独立项目，不要求复制提示词或另开会话。

首次/重装 QQ 聊天时，基础检查和机器人身份核对通过后，由 Agent 打开 AuraBot 总开关并关闭试运行，读回核对，再请主人发消息验收；用户明确选择试运行时遵从。已知客户端崩溃先排障，不循环加载或重启主号。
