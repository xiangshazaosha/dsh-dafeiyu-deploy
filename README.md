# DSH 大肥鱼按需部署 Skill

面向已安装 DeepSeek Harness 的用户，按需检查和部署大肥鱼桌宠、Aurabot QQ、聊天语音、RVC 翻唱、歌曲来源、成品库和社交模块。支持只检查、只补缺项，不默认安装整套。

## 使用

将本仓库交给有文件操作能力的 DSH Agent，要求它安装此 Skill，阅读 `SKILL.md` 并按需求执行。普通下载、解压和配置由 Agent 完成；扫码、账户验证与需要本人处理的许可步骤由用户完成。详细规则和版本兼容性见 `SKILL.md` 与 `references/`。

SnowLuma 缺失时仅告知：“由于许可协议问题本项目无权提供自动部署，请自行安装，完成后告诉我目录”。其他独立项目继续执行；用户提供目录后检查与接入。

本项目不包含 DSH、Aurabot、QQ 网关、基础声音模型权重、歌曲、个人配置或登录凭据。另附十二款小型合成音色预设及独立非商用许可；基础组件仍需独立获取并遵守其许可。网易云、QQ 与各组件的接口可能变化；CPU 路线和其他机器的功能必须各自验证。

已补入按需的 Breeze TTS 2 第三方 C++/Vulkan 本机语音、原有四款原创合成音色准备、RVC 追加音色校验导入、独立可见的讲话/翻唱音色与回复方式设置（仅文字/仅语音/文字＋语音/自动），以及既有QQ网关断线的定向检查修复。脚本使用实际路径、默认只检查；不包含基础模型或个人资料，不因选择其中一项而安装全部。详见 `references/breeze-tts2-cpp.md`、`rvc-extra-voices.md`、`voice-controls.md` 与网关故障参考。

新增可直接导入的固定讲话音色：**撒娇女友、御姐女王、懒羊羊风格（近似）、台湾女生·巨甜普通话、傲娇大小姐、迷糊女大学生、霸道女总裁、男高中生、男大学生**。十二款 `.breeze` 共约81KB，附SHA256、风格指令和只读/无覆盖导入脚本；保留当前讲话、翻唱和回复方式。台湾女生这款说普通话并保留自然台湾腔，懒羊羊这款只是合成近似、非动画原声。见[固定音色包](references/breeze-saved-presets.md)。

首次安装、重装或补齐功能均面向普通用户，不另设教学专用版。先独立查找已有 SnowLuma，不依赖旧 Aurabot 配置；已安装就复用，确认缺失才补装。只读定位助手为 `scripts/find-snowluma.ps1`；控制台凭据、账号定向接入及 QQ 加载闪退见 `references/snowluma-setup-and-reuse.md`。基础准备完成仍有待办时，直接说明最少的人工操作并在完成后继续，不要求复制提示词或另开会话，也不默认要求用户登录网页反复手动加载。

首次/重装 QQ 聊天时，基础检查和机器人身份核对通过后，由 Agent 打开 AuraBot 总开关并关闭试运行，读回核对，再请主人发消息验收；用户明确选择试运行时遵从。已知加载崩溃先排障，不循环加载主号。
