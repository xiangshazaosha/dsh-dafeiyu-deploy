# DSH 大肥鱼按需部署 Skill

面向已安装 DeepSeek Harness 的用户，按需检查和部署大肥鱼桌宠、Aurabot QQ、聊天语音、RVC 翻唱、歌曲来源、成品库和社交模块。支持只检查、只补缺项，不默认安装整套。

## 使用

将本仓库交给有文件操作能力的 DSH Agent，要求它安装此 Skill，阅读 `SKILL.md` 并按需求执行。普通下载、解压和配置由 Agent 完成；扫码、账户验证与需要本人处理的许可步骤由用户完成。详细规则和版本兼容性见 `SKILL.md` 与 `references/`。

本项目不包含 DSH、Aurabot、QQ 网关、声音模型、歌曲、个人配置或登录凭据。对应上游需独立获取并遵守其许可。网易云、QQ 与各组件的接口可能变化；CPU 路线和其他机器的功能必须各自验证。
