# 可见的讲话/RVC 音色与回复方式设置

用户找不到切换入口、要求设置按钮或修改回复文字/语音方式时读取。保留现有声音和聊天行为；只是装入口时不要自作主张切成全语音。

## 为什么原来的说法会找不到

Aurabot 1.1.24 用户替换 `voice` 后，状态可同时是 `running='user'` 与 `builtin=true`。该版前端 `hasUi` 要求 `running==='user' && !builtin`，因此模块运行成功、有 settings schema，仍会隐藏自动表单。不能再仅凭源码 schema 告诉用户“语音页下面一定有按钮”。先核对当前客户端导航与服务状态，版本更新后再判断。

不要为了可见性直接改包管理器共享的核心 client 文件。`assets/voice-controls/` 是独立非内置用户模块，单独 `panel.js`，走宿主扩展入口；不覆盖正常语音模块，也不携带账号、文件或固定部署路径。

## 安装和真实入口

Agent 在所选功能范围内完成：

1. 核对当前模块 API 及 `/modules/panel`，再运行 `scripts/install-voice-module.mjs --plugin-dir <实际插件> --data-dir <实际数据> --module voice-controls` 检查；通过后 `--apply`。已有不同自定义版本必须审查、备份，明确替换才用 `--replace --backup-dir <新备份目录>`。
2. `/modules/reload` 只重载 `voice-controls`，不重启 QQ/DSH，不改变自动社交。检查 `running=user,builtin=false,panel=true,error=''`、`/ext/voice-controls/state` 返回实际语音/RVC列表、`/modules/panel?id=voice-controls` 返回有效面板。
3. 核对当前导航源码或可观察页面，不默认使用电脑控制。经验证的 1.1.24 两层导航：**DSH主窗口 → 左侧 Aurabot（鲸鱼图标）→ 上排“系统”→ 下排“音色切换”**；也可在 Aurabot 内 `Alt+K` 搜“音色切换”。不是悬浮鱼自身的右键菜单。尚未出现先离开页面再回来，不默认重启宿主。实际版本入口不同则以当前证据为准；需要截图可请用户提供，电脑操作仍遵从用户工具约束。
4. 展示列表和当前值，验证分别保存互不串改；最终说清是否只是源码/API验证，是否已目视看到用户界面。不要把静态渲染测试当屏幕截图。

## 讲话和 RVC 分开

- “保存讲话音色”只更新 `ext.voice.breezeVoice`，实际候选从运行中的 Breeze 语音模块读取；未加载时明确不可用，不伪造四个按钮成功。
- “保存翻唱音色”只更新 `song.voice`，列表从当前 `song.status()` 取得。保留肥鱼原模型；新增五款安装后应共六款。
- 这里不设置 `voice.songVoice`。那是另一个“TTS 后再 RVC”的功能，不能假称选了神里绫华翻唱就让讲话也自动变角色声音；当前 Breeze 适配未接这层转换。
- 新选 RVC 不重做现有歌曲库成品。已缓存/持久成品优先扩展可能发旧制作；想用新音色制作另一个版本需明确新制作，不能伪造库的声音元数据。

## 回复方式不是把概率设成 100%

面板顶部“回复方式”有四项，点击“保存回复方式”，从下一次普通 QQ 回复生效：

| 选项 | 真正行为 |
|---|---|
| 自动混合（默认） | 保持原有语音概率、模型选择和语音意图，不强制每条 |
| 仅文字 | 在 `reply/items` 阶段把 text/voice 项转为 text，不调用朗读 |
| 仅语音 | text/voice 项转为 voice，长内容按 UTF-16 安全分段，不静默截断 |
| 文字＋语音 | 每段先文字再相应语音，不是随机混合 |

只影响聊天中枢 deliver 的普通聊天文字/朗读项；固定命令提示、直接发文件、图片表情、翻唱成品与桌宠气泡不被改写。引用属性保留，图片等非文字项保留；文字＋语音会增加消息条数，群聊需结合现有频率/刷屏限制短片段验收，不因新开关放宽白名单或主动回复决策。仅语音/双发会打开 `voice.enabled`，但语音模块不在运行时拒绝保存并解释；不偷偷开其它模块。自动/文字模式不改原来的概率或语音总开关。

`reply/items` 在随机语音之后执行，才可兜住模型显式 `<voice>`、用户语音意图和概率转换。只设 `voice.autoChance=1` 仍受长度/心情等影响，不是全语音。语音合成或网关失败时中枢仍会保底文字，必须告诉用户“仅语音”不是故障时也绝不发文字；双发失败可能再有文字兜底，不报成语音已发。

## 离线测试和回退

- `node scripts/test-voice-controls.mjs`：状态、分开保存、字段保留、非法ID/模式拒绝、长文本不丢字、实际渲染三个选择框/保存按钮。
- `node scripts/test-reply-mode-hub.mjs --plugin-dir <实际Aurabot包>`：在临时数据目录调用已安装真实聊天中枢，用本地生成 WAV 替身捕获 text/record 消息段，验证仅文字不调 TTS、仅语音、双发、自动和合成失败保底，网关调用必须为零。不是新合成/音质/收件人播放验收。
- 新部署默认保留 auto 及原声音；只读 API 回来符合不代表当前用户已点击。需要真实回复验收时由主人发一句话，不向第三方试发。
- 禁用“音色切换”模块会撤掉回复方式钩子、恢复原有普通回复行为，不卸载声音。替换前备份源文件，回退只恢复本模块；不把整份旧用户配置覆盖回去。
